# Data

`customer_churn.csv` is generated by `src/generate_data.py`. Every record is synthetic and represents one subscription customer.

| Field | Description |
|---|---|
| `customer_id` | Synthetic identifier |
| `tenure_months` | Months since subscription began |
| `monthly_charges` | Monthly subscription charge |
| `support_tickets` | Support tickets in the recent period |
| `contract_type` | Month-to-month, one-year, or two-year contract |
| `payment_method` | Synthetic payment channel |
| `paperless_billing` | Whether paperless billing is enabled |
| `internet_service` | DSL, fiber, or no internet service |
| `avg_monthly_usage_gb` | Average monthly data usage |
| `late_payments` | Recent late-payment count |
| `region` | Synthetic Canadian region grouping |
| `churn` | Binary target: 1 indicates churn |
